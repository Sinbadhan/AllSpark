# AllSpark 极客设计风格规范

## 核心原则

AllSpark 是一个**离线人工智能生存系统**，面向极客/生存主义者。界面风格应传达：
- **冷峻精确**：像终端/航天仪表盘，而非消费级 App
- **信息密度高**：一眼获取关键状态，减少冗余装饰
- **中英统一**：所有输出走 i18n t() 函数，禁止硬编码混用

## 色彩体系

| 语义 | 色值 | 用途 |
|------|------|------|
| PRIMARY | `#ff6b35` (橙焰) | 标题、强调、品牌色 |
| CRITICAL | `#ff4444` (红) | 危急/紧急 |
| WARNING | `#ffaa00` (琥珀) | 警告/紧张 |
| SUCCESS | `#44cc44` (绿) | 正常/完成 |
| INFO | `#4488ff` (蓝) | 信息/提示 |
| BG | `#0a0a0a` | 主背景 |
| CARD | `#141414` | 卡片/面板背景 |
| BORDER | `#2a2a2a` | 边框/分割线 |
| TEXT | `#e0e0e0` | 主文本 |
| DIM | `#666` | 弱文本/注释 |

## 字体

- CLI: 终端默认等宽字体（Rich Console 自动处理）
- Web: `"JetBrains Mono", "Fira Code", "SF Mono", monospace`（代码/数据）+ 系统无衬线（正文）

## CLI 规范

### 布局
- 使用 Rich Table/Panel 对齐，禁止手动空格对齐
- 标题用 `Panel`，数据用 `Table`，行内状态用 emoji+色标
- 分隔线: `━━━` (Rich rule)，不用 `---` 或 `===`

### 状态显示
- 资源未接入: 显示 `◇ 未接入` (dim)，不显示 0
- 资源正常: 显示值 + 单位 + 剩余时间
- 资源告警: 值 + 红色/琥珀色标记
- emoji 仅用于语义标记，不做装饰

### 命令反馈
- 成功: `[green]✓[/]` 前缀
- 失败: `[red]✗[/]` 前缀
- 警告: `[yellow]⚠[/]` 前缀
- 信息: `[dim]◇[/]` 前缀

### i18n 硬性规则
- **所有面向用户的字符串必须走 `t()` 函数**
- 禁止在 `cli.py`、`daily_briefing.py`、`web_ui.py` 等展示层硬编码中文或英文
- `_t(zh, en)` 辅助方法仅用于简单二元选择，复杂文本统一用 `t()`

## Web UI 规范

### 布局
- 深色背景，无圆角阴影装饰（圆角最大 8px）
- 卡片边框 1px solid，不用 box-shadow
- 信息区用等宽字体显示数值

### 资源卡片
- 未接入: 显示 `--` 占位 + dim 文字 "未接入"
- 有数据: 显示数值 + 进度条 + 状态色标
- 进度条颜色: >70% 绿 / 30-70% 琥珀 / <30% 红

### 动效
- 禁用花哨动画，仅保留: 渐变色过渡、状态闪烁(危急)

## 术语对照表

| 中文 | English | 用途 |
|------|---------|------|
| 火种 | AllSpark | 品牌名 |
| 未接入 | OFFLINE | 资源无数据 |
| 危急 | CRITICAL | 红色告警 |
| 紧张 | LOW | 琥珀告警 |
| 正常 | OK | 绿色状态 |
| 休眠 | HIBERNATION | 模式名 |
